# VANTAGE Visual

Frontend of **VANTAGE**, a web application being prepared for the 2026 NASA Space Apps Challenge.

> **Status: In Preparation.** Development has not started yet. This repository currently contains project documentation only.

## About VANTAGE

VANTAGE turns open Earth-observation hazard data into clear, map-based information about landslide hazard and road accessibility for communities in Costa Rica, so that people and local institutions can understand how a hazard may affect them.

## Purpose of this repository

`vantage-visual` holds the client side of VANTAGE: an installable progressive web app (PWA) that presents the information produced by the VANTAGE backend through maps, statistics and location-based views. All data processing and modeling happen in the backend; this application only consumes its REST API.

## Planned scope

- Interactive 3D globe and country map showing hazard levels.
- Statistics view by canton.
- "My zone" view with location-based information and guidance.
- Institutional view for prioritizing road segments.
- Citizen report form.
- Offline support and installation as a PWA.

The scope may change as the project evolves.
